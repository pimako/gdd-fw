# spec-implement — 実装フェーズ

## 前提チェック

`.specs/<slug>/tasks.md` が存在しない場合は、先に `spec-tasks` を完了させるようユーザーに促し、ここでは進めない。

## 手順

1. `.specs/<slug>/spec.md`, `design.md`, `tasks.md` を読む。
2. `tasks.md` の未完了タスクを上から順に(依存関係を尊重して)実装する。ユーザーが特定のタスク番号を指定した場合はそれを優先する。
3. 各タスクについて:
   - design.md の方針に沿って実装する。方針から外れる判断が必要になった場合はユーザーに確認する。
   - 実装後、そのタスクの `tasks.md` の チェックボックスに `[x]` を付ける。
   - 意味のある単位ごとに立ち止まり、まとめて全タスクを無言で終わらせない(ユーザーが途中で介入できるようにする)。
4. 一度に大量のタスクを進める場合、タスクごとの差分が大きくなりすぎないよう注意する。
5. すべての対象タスクが完了したら `.specs/<slug>/STATE.md` を更新(`current_phase: implement`、進捗チェック、`updated_at`)。
6. 次は `spec-test`(テストがある場合)または `spec-review` に進むことを案内する。
