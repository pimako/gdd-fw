# gate-status — 進捗確認

## 手順

1. 対象プロジェクト直下の `.specs/` ディレクトリを探索する。存在しなければ、まだGDDパイプラインが開始されていない旨を伝え `gate-init` を案内する。
2. `.specs/BACKLOG.md` を読み、全ストーリーの一覧(優先度・見積り・ステータス・所属イテレーション)を表示する。
3. `.specs/iterations/` を確認し、アクティブなイテレーション(`PLAN.md`はあるが`RETRO.md`が無い最新のもの)があれば、そのゴールと対象ストーリーの進捗を示す。
4. 各ストーリーについて `.specs/stories/<slug>/` 配下のファイル(STORY.md/DESIGN.md/TASKS.md/TEST.md/CHECK.md)の有無から、現在どのgate-*フェーズまで完了しているかを判定する。
5. 矛盾がある場合(例: ステータスは進んでいるのに対応ファイルが存在しない)は、その旨を注記する。
6. `.specs/PERSONAS.md` が未設定であれば、`gate-team` の実行を推奨する一文を添える。
7. ユーザーが特定のストーリーについて続きを進めたそうであれば、次に実行すべきgate-*スキルを提案する。
